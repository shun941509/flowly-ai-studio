# 로컬 RAG 자료 수명주기

2026-10-24. `knowledge`(지식 색인 관리) 노드는 준비·평가·발행·조회·철회·복구·현황 작업을 제공합니다. 웹은 설계와 내보내기만 제공하며 OpenAI를 호출하지 않습니다. Node.js와 Python 실행기는 같은 입력 계약과 저장 규칙을 사용합니다.

## 실제 동작

1. **준비(stage)**: 등록된 허용 자료의 스냅샷, 또는 해당 자료 ID에 한정한 `{resourceId,version,content}` 변경 문서를 받습니다. 현재 발행 세대에서 변경하지 않은 자료를 이어받고 변경 문서의 본문을 고정 크기로 다시 나눕니다. 출처 ID·본문·임베딩 모델 해시가 같은 조각의 벡터를 재사용합니다. 새 조각과 바뀐 조각만 제공자에 전달합니다. 조각 경계가 바뀌면 그 영향 범위의 조각도 새로 임베딩합니다.
2. **평가(evaluate)**: 등록한 질문을 후보 세대에 실제로 검색하고 정답 자료 ID가 결과에 있는지 확인합니다. 모델의 자기 평가 점수가 아닙니다. 이 검사는 검색 재현 여부이며 답변의 의미적 정답률이나 운영 데이터 품질을 보증하지 않습니다.
3. **발행(publish)**: 모든 평가 질문을 통과했고 평가 이후 철회 상태가 바뀌지 않은 후보만 활성 세대로 전환합니다. 준비 중인 후보는 기본 검색에 노출되지 않습니다.
4. **조회(query)**: 현재 활성 세대에서 허용 자료만 검색합니다. 결과에 세대·자료 ID·자료 버전·원문 조각·순위 점수를 반환합니다. 명시적으로 준비 중인 후보나 비활성 과거 세대를 조회하려 하면 거절합니다. 후보 검색은 평가 작업에서만 수행합니다.
5. **철회(revoke)**: 선택한 허용 자료 ID를 되살릴 수 없는 로컬 철회 목록에 등록합니다. 모든 보관 세대의 해당 조각과 사용하지 않는 벡터를 제거하고 기존 평가를 무효화합니다. 같은 색인 이름 안에서 철회 문서를 다시 준비할 수 없습니다.
6. **복구(rollback)**: 이전에 발행했던 세대 중 현재 철회 상태로 재평가를 통과한 세대만 활성화합니다. 철회 자료는 이전 세대에서도 제거되어 복구되지 않습니다.
7. **현황(inspect)**: 현재 리비전, 활성 세대, 보관 세대별 조각 수·평가 상태와 허용 자료의 철회 목록을 반환합니다.

## 저장과 실행 계약

- 저장 범위는 실행기 소유자 ID + 루트 워크플로 ID + 색인 이름입니다. 다른 사용자나 워크플로의 상태를 읽지 않습니다.
- 기존 실행기 잠금·파일 동기화·원자적 교체를 이용합니다. 변경 직전 리비전을 원자적으로 비교하여 동시에 만든 후보가 최신 상태를 덮어쓰지 못하게 합니다. 충돌하면 최신 상태를 확인하고 새 실행으로 다시 요청합니다.
- 실행 ID와 노드 ID를 작업 ID로 사용합니다. 같은 변경을 재개하면 저장된 메타데이터 결과를 재사용하며 변경된 인자의 재사용은 거절합니다. 모델 임베딩은 저장 직전에 프로세스가 중단된 경우 다시 호출될 수 있지만 활성 상태 변경은 중복되지 않습니다.
- 색인 상태는 메모리 어댑터의 일반 읽기·쓰기 결과 이력에 복제하지 않습니다. 자체 작업 이력에는 세대 ID·수량·평가 결과 등만 보관하여 철회한 원문을 숨은 메모리 이력에 남기지 않습니다.
- `expectedRevisionPath`를 지정하면 입력에 있는 리비전과 현재 리비전도 비교합니다. 명시하지 않아도 저장 시 리비전 비교는 항상 적용합니다.
- 색인당 보관 세대 8개, 세대당 조각 100개, 변경 작업 기록 128개, 직렬화된 상태 200,000자 제한입니다. 자료 1~20개, 본문당 40,000자, 평가 질문 1~10개, 검색 결과 1~10개입니다. 한도 초과는 저장하지 않고 실패합니다. 자동 세대 정리나 벡터 DB 서비스는 이번 구현에 포함하지 않습니다.

## 권한과 삭제의 범위

작업 시작, 조회 자료 선택, 저장 직전에 허용 자료 접근 검사를 호출합니다. 웹에서 새 ZIP을 만들 때 현재 자료 공유 권한을 다시 확인합니다. **이미 내보낸 ZIP은 오프라인 복사본이므로 원격 공유 철회를 감지하거나 회수하지 못합니다.**

로컬 철회가 삭제하는 범위는 현재 색인 저장 파일의 모든 세대·벡터·색인 작업 이력입니다. `workflow.json`에 포함된 자료 스냅샷, 이전 실행 결과·로그, 사용자가 만든 백업이나 다른 사본까지 지우지 않습니다. 이 파일들의 보존·삭제는 별도로 관리해야 합니다. 공유받은 자료의 외부 자격 증명을 가져오지 않습니다.
