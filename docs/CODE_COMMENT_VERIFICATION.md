# 코드 설명 주석 작업과 검증 기록

작업일: 2026-10-27. 이 문서는 **기능 구현 승인 전에 수행한 주석 단계**의 기준 기록이다. 이후 사용자가 첨부 기능 구현도 함께 진행하도록 확정하여 실제 기능 변경을 추가했다. 아래 AST 동일성·검사 결과를 이후 기능 변경의 증거로 재사용하지 않는다. 현재 구현과 최종 검증은 [자료 통합 구현 기록](RESOURCE_EXPERIENCE_IMPLEMENTATION.md)을 따른다.

## 변경 내용

- 소스 221개에 한국어 설명 주석 1,255줄을 추가했다.
- 파일의 책임, 주요 함수의 계약, 데이터 전달, 편집 상태, 권한·승인·재개·중복 방지의 이유를 설명했다.
- 현재 지원 범위와 미지원 범위를 구분했다. Skill 텍스트 처리와 임의 코드 실행, 테스트 대역과 실제 모델 품질을 혼동하지 않도록 했다.
- [코드 읽기 안내](CODE_READING_GUIDE.md)를 만들고 README에서 연결했다.
- 주요 도메인 설명, 서버 경계, 작성된 가이드는 다른 작업자의 읽기 전용 검토를 거쳤다. 실제 코드와 어긋난 표현을 수정했다.

벤더 UI와 벤더 Vite 플러그인, 생성된 카탈로그 원본에는 반복적인 주석을 직접 넣지 않았다. 단순 대입·표시 헬퍼의 각 줄을 번역하는 대신 분석에 필요한 계약과 경계를 설명했다. 사용자 화면 문구와 내보낼 문서 문자열을 코드 주석으로 취급해 바꾸지 않았다.

## 주석 외 변경 검사

작업 시작 시점의 기존 수정 사항을 포함한 소스 223개를 기준본으로 남겼다. Git HEAD가 아닌 이 기준본과 비교해 기존 사용자 수정 사항을 이번 작업과 구분했다.

- 변경된 TS/TSX/MJS/타입 파일 196개: 주석을 제외한 AST와 TypeScript 생성 코드 일치. 선언 전용 파일은 AST로 검사.
- 변경된 Python 19개: 위치 정보를 제외한 AST 일치. 기존 docstring은 보존하고 `#` 주석을 추가.
- 변경된 CSS 6개: 주석을 제거한 PostCSS 구조 일치.
- **구문·생성 코드 불일치: 0개.**

기준본 비교와 파일별 해시는 `outputs/comment-review/1793030737643/semantic-verification.json`에 보관했다. 임시 비교 도구와 기준본도 같은 Git 제외 디렉터리에 있다.

주석 역시 소스 바이트를 바꾸므로 내보낸 도구의 무결성 해시와 예제 증거 지문은 달라진다. 기존 다운로드 폴더나 저장된 실행 상태를 수정하지 않았으며 지문 검사를 약화하지 않았다. 생성 번들과 현재 예제 증거는 새 소스 기준으로 다시 만든다.

## 실행한 검사

| 검사 | 결과 |
|---|---|
| 기준본과 주석 외 구문 비교 | 223개 비교, 변경 221개, 불일치 0개 |
| `pnpm typecheck` | 통과 |
| `pnpm lint` | 통과 |
| `pnpm test` | 753개 중 통과 751, 실패 0, 건너뜀 2 |
| `git -c core.safecrlf=false diff --check` | 통과 |
| 주석 단계 예제 Node.js/Python ZIP 검사 | 226/227 통과, 대량 페이지 보완 입력 1개 실행 한도 실패 |
| `pnpm build` | 주석 단계에서 미실행. 이후 통합 기능 단계에서 별도 실행 |

건너뛴 2개는 `tests/python-tools-export.test.ts`의 RPA Node.js/Python 실행 검사다. 현재 로컬 환경에 Playwright Chromium이 없어 `missing_configuration`으로 건너뛰었다. 의존성이 없는 상태를 실행 성공으로 계산하지 않았다. 이번 주석 작업을 위해 브라우저나 추가 패키지를 설치하지 않았다.

전체 테스트에는 실제 ZIP 실행, Agent 없는 프로젝트, 동적/병렬/중첩 작업, 입출력, 승인·거절·재개, 상태 보존, 권한 경계 및 웹 실제 실행 차단 검사가 포함된다. 성공한 테스트 범위를 실계정 서비스 연결 성공으로 확대하지 않는다.

예제 검사 첫 실행에서는 대량 페이지 보완 입력 예제가 하네스의 기본 CLI 제한 30초를 넘었다. `--timeout-ms 120000`으로 하네스 대기 한도를 늘린 재검사는 226/227 통과, 2,404개 검사를 기록했고 대량 페이지 Python 실행은 budget_exceeded를 반환했다. 해당 단계 보고서를 outputs/comment-review/1793030737643/comment-phase-workflow-verification.json에 보관했다. 이후 기능 변경으로 지문이 달라졌으므로 최종 예제 증거는 통합 단계에서 다시 생성한다.

## 외부 호출·설정·미검증 범위

- 실제 OpenAI·원격 MCP 서비스 호출: **없음**. 모델·MCP 경계에는 명시적인 테스트 응답을 사용했다.
- 자격 증명 조회·복사·등록이나 사용자 워크플로/자료 DB 이관을 수행하지 않았다.
- 주석만으로는 추가 설정이 없었다. 이후 첨부·실행 기능의 설정은 통합 구현 문서에 별도로 기록한다.
- RPA 실행 검증에는 별도 Playwright Chromium 준비가 필요하다.
- 실제 SSO·모델·MCP 계정 연결과 실제 모델 정답률은 이번 작업에서 검증하지 않았다.
- 로컬 웹 서버/DB를 대상으로 하는 `pnpm test:integration`과 수동 브라우저 UI 검사는 이번 주석 작업에서 실행하지 않았다.
