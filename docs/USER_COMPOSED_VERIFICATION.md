# 사용자 조합 워크플로의 내보내기 검증

> 2026-10-26 현재 통합 계약: [통합 사용자 기능 명세](INTEGRATED_USER_WORKFLOW.md), [최신 검증 결과](INTEGRATED_VERIFICATION.md). 아래 날짜별 기록은 당시 구현·검증 범위입니다. Agent 다운로드의 Agent 필수 조건은 철회되었으며, 워크플로는 별도 읽기·지정 수정 공유를 지원합니다.

이 문서는 기존 이름 붙은 예제를 선택하는 방식과 별도로, 사용자가 서로 다른 블록을 조합한 새 설계가 실제 내보낸 실행기에서 동작하는지 확인한 기록입니다. 검증 전용 설계는 공개 예제 목록·개수에 포함하지 않습니다.

## 검증 경계

- 동일한 설계로 일반 실행 프로젝트와 Agent 프로젝트를 각각 Node.js·Python으로 생성합니다. 6개 설계 × 2개 묶음 × 2개 언어 = **24개 ZIP**입니다.
- 각 ZIP을 풀고 그 안의 실제 `runner.mjs`·`runner.py` 또는 `agent.mjs`·`agent.py` 진입점을 새 프로세스로 실행합니다.
- 모델·MCP의 HTTP 응답만 명시적인 테스트 응답으로 대체합니다. 네트워크 소켓 연결을 차단하고, 상위 프로세스의 자격 증명 환경 변수를 넘기지 않습니다.
- 분기·입출력 매핑·규칙 평가·병렬·반복·메모리 저장·승인·보완 입력·체크포인트·재개는 실제 실행기 코드가 처리합니다.
- Agent용 Python 검증은 먼저 원래 `agent.py`의 파일 검사를 수행하고, 해당 진입점이 실행하는 실제 `runner.py`에만 테스트 HTTP 경계를 적용합니다. 제품 ZIP이나 실행 정의는 변경하지 않습니다.
- 로그에 실행 모드가 `live`로 표시되더라도 이 검증의 모델·MCP 응답은 테스트 응답입니다. 실제 OpenAI·MCP 외부 API 호출은 **0회**입니다.

## 동일 설계·동일 동작 검사

내보낸 `workflow.json`을 기존 스키마 기본값을 적용한 원래 설계와 대조합니다. 문서에 모든 중첩 노드가 포함되는지, Agent 구성 목록이 실제 Agent 수와 일치하는지, ZIP에 `.env`나 테스트 fixture가 들어가지 않는지도 확인합니다.

네 경로의 결과는 다음 관찰 가능한 계약으로 비교합니다.

- 최종 상태와 결과
- 완료·건너뜀 노드의 횟수
- 하위 작업별 경로·상태·결과
- 모델·도구 호출 횟수
- 사용한 턴·도구·토큰 수
- 보완 입력의 대상·상태
- 승인 대상 노드·도구·정확한 인자·결정

실행 ID·타임스탬프·소요 시간은 환경마다 달라질 수 있어 동등성 비교에서 제외합니다. 병렬 실행은 순서를 강요하지 않고 실제 실행 구간이 겹치는지 별도로 확인합니다.

## 재현 명령과 증거

```powershell
pnpm exec tsx --test tests/user-composed-export.test.ts
```

검증 파일:

- `tests/fixtures/user-composed-workflows.ts`: 카탈로그에 의존하지 않는 새 설계와 명시적인 시나리오
- `tests/user-composed-export.test.ts`: ZIP 생성·실제 CLI 실행·네 경로 결과 비교
- `tests/workflow-export-integration.ts`: 기존의 환경 격리·프로세스 실행·입력/승인/검토 재개 보조 함수 재사용
- `tests/workflow-node-preload.mjs`, `tests/workflow-python-boundary.py`: 기존의 네트워크 차단·HTTP 경계 재사용

`work/user-composed-verification/<조합>-evidence.json`에 각 ZIP 해시, 실행 계약, 실제 작업 폴더를 남깁니다. 작업 폴더에는 명령별 결과와 실행 기록이 있어 실패 원인을 다시 확인할 수 있습니다.

현재 작성 환경은 Windows, Node.js 26.5.0, Python 3.13.3입니다. 최소 지원 버전 및 다른 운영체제의 전체 행렬 검사를 의미하지 않습니다. 실제 모델의 판단 품질, 실제 MCP 서비스의 호환성, 임의의 모든 그래프 조합을 증명하는 결과도 아닙니다.

## 사용자 설정

웹은 OpenAI를 호출하지 않습니다. 사용자는 도구 및 자료에 MCP 정의를 등록하고, 내려받은 프로젝트의 `.env.example`을 `.env`로 복사해 모델 키·모델 이름·MCP 주소/토큰을 설정합니다. 이 검증에서 사용한 테스트 응답과 토큰은 제품 ZIP에 포함하지 않습니다.
