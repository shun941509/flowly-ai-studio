# 외부 AI 전달·수정본 가져오기

2026-10-26 구현 기록입니다. 이전 문서의 ‘Agent 블록이 있어야 다운로드 가능’ 조건은 철회했습니다.

## 구현

- Agent가 없는 설계도 Agent 다운로드를 제공합니다. 서버·UI·패키지 생성·Node.js/Python 전용 진입점이 빈 Agent 목록을 허용하며, 원래 그래프에 Agent를 추가하지 않습니다. 설계 오류·자료 권한 검사는 그대로 적용합니다.
- AI 명령 프롬프트는 복사 기능입니다. `설계대로 실행`, `요청한 부분 수정 후 실행`, `설계를 바탕으로 프로젝트 구성`을 선택할 수 있습니다. 짧은 시작 지시와 전체 설계·자료·실행 정책을 포함한 상세 지시를 구분합니다.
- Agent 다운로드에는 START_HERE.md, AI_START.md, AI_PROMPT.md, AGENTS.md, Agent.md, WORKFLOW_GUIDE.md, CORE_TERMS.md, 선택 Skill, MCP 정의, workflow.json, 언어별 실행기, 설정 예시를 포함합니다. 문서와 복사 프롬프트는 서버에서 현재 접근 가능한 자료로 만든 같은 실행 정의를 사용합니다. 역할별 지침은 실제 Agent가 있는 만큼만 만듭니다.
- 파일명은 프로젝트 이름·초안/발행 버전·날짜·언어·종류를 포함합니다. 실행 정의의 origin은 원본 ID·기준 수정 시각·스키마 버전과 발행 버전 정보를 구분합니다.
- 외부 수정본 가져오기는 웹 JSON과 실행기 workflow.json, 프로젝트 ZIP을 읽습니다. 임의 코드는 실행하지 않습니다. 원본·기준 시각, 중첩 블록·연결·이름·설명 변경, 현재 자료 재연결과 설계 검사를 보여 줍니다.
- 새 사본은 별도 ID와 비공개 권한으로 저장합니다. 원본의 새 버전은 현재 설계 ID·기준 시각 일치 및 편집 권한이 필요합니다. 이전 발행본이나 원본이 변경된 경우에는 사본으로 보관합니다. 서버가 현재 자료 권한·편집 권한·동시 저장을 다시 검사합니다.
- ZIP의 PROJECT_FILES.json은 파일 비교 기준입니다. 수정된 실행기 코드는 별도로 표시하고 캔버스로 복원했다고 주장하지 않습니다. JSON만 가져오면 실행기 코드 변경 여부는 확인 불가로 표시합니다.

## 외부 수정과 문서 갱신

내보낸 폴더에서 `python project-check.py`를 실행하면 내보낸 기준과 달라진 파일을 확인할 수 있습니다. 이 검사는 서명·안전성·실서비스 성공 검증이 아닙니다. 비밀 설정이나 사용자 입력·결과 파일을 읽어 웹에 전송하지 않습니다.

설계를 수정한 뒤에는 workflow.json을 웹으로 가져와 비교·자료 재연결·검증 후 저장하고 다시 내보냅니다. 문서·실행 정의·표준 실행기·파일 비교 기준이 함께 갱신됩니다. 임의로 수정한 실행기 코드는 재내보내기에 합쳐지지 않으므로 별도 개발 브랜치에서 검토·테스트합니다. 내보낸 ROUNDTRIP.md에 이 절차를 포함합니다. 변경된 설계는 새 실행으로 시작하며 이전 승인·체크포인트를 재사용하지 않습니다.
