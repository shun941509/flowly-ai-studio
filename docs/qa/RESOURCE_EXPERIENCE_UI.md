# 자료·편집기 경험 브라우저 검증

검증일: 2026-10-27. Chrome에서 `http://127.0.0.1:5190/studio`의 개발 테스트 인증 Alice 계정으로 확인했다. 5190 서버는 사용자 운영 중인 5173 서버와 D1·첨부 저장소가 분리된 검증 환경이다. 실제 OpenAI·MCP 서비스에 연결하거나 자격 증명을 입력하지 않았다.

이 문서는 실제 화면 조작으로 확인한 범위를 기록한다. 소스 검사, HTTP 권한 검사, 내보낸 실행기의 검증과 구분한다. 브라우저 검사 중 통합 HTTP 검사의 세션 회수에 영향을 받은 뒤에는 새로운 저장 작업을 진행하지 않았다. 최종 빌드 및 5190 재시작 후 Alice 테스트 로그인을 다시 수행하여 수정된 문구와 가져오기 화면을 확인했다.

## 발견하여 수정한 화면 문제

- 사용자 확인 날짜가 UTC 기준으로 기본 설정되어 한국 시간의 날짜와 하루 달라질 수 있었다. 로컬 달력 기준으로 기본값·선택·표시를 맞췄다.
- 첨부 파일 본문 편집란에 접근성 이름이 없었다. `<파일명> 내용` 이름을 추가했다.
- Python 도구 설정 자료의 연결 블록 설명에 일반 자료 안내가 노출되었다. Python 프로그램 및 Agent의 허용 Python 도구에서 해당 도구 ID를 선택하도록 설명을 구분했다.

위 세 수정은 최종 빌드의 실제 화면에서도 재확인했다. 파일 편집 입력란의 접근성 이름 `scripts/run1.py 내용`, 날짜 `2026-10-27`, Python 프로그램 및 Agent 허용 Python 도구 문구를 확인했다. 최종 재확인 시 브라우저 콘솔 오류 로그가 없었다.

## 미검증 및 제한

- Chrome 확장의 `Allow access to file URLs`가 꺼져 있어 자동화 파일 선택기의 `setFiles` 단계가 차단되었다. 확장 보안 설정을 변경하지 않았다. 따라서 브라우저에서 파일을 선택하여 업로드 완료하는 전체 경로는 미검증이다. 테스트 파일은 검증용 `reference.txt`·`validate.py`이며 사용자 파일을 업로드하지 않았다.
- 별도 HTTP 검사에서 수행한 첨부 업로드·다운로드·권한 재검사와 Node.js·Python ZIP 실행은 통합 보고서의 범위이며, 이를 브라우저 파일 선택 성공으로 대신 표시하지 않는다.
- 좁은 화면은 예제 상세 창과 외부 수정본 가져오기 초기 화면을 확인했다. 모든 설정·자료 유형 및 모바일 기기의 전수 검증은 아니다.
- 중첩 오류의 이동은 기존 경로·메시지에 따른 탭 및 첫 필드 초점을 사용한다. 모든 오류에 구조화된 정확한 필드 ID가 제공되는 것은 아니다.
- 일부 고급 설정은 JSON 편집을 유지한다. 모든 JSON 설정이 입력 양식으로 바뀌었다고 보고하지 않는다.
- 195개 Python 도구의 설명은 실제 소스의 반환 필드·공통 구현·제약을 분류한 결과다. 이 브라우저 검증에서 195개 알고리즘을 실행하거나 실제 모델 성능을 검증하지 않았다. 자세한 범위는 [소스 감사 기록](../PYTHON_TOOL_SUPPORT_AUDIT.md)을 참고한다.

## 데이터 보존

브라우저에서 지속 저장한 항목은 격리 Alice 계정의 `컴퓨터 사용 실행 설정` 검증 자료다. 별도 API로 만든 `UI 검증 Skill 파일과 두 실행`, `UI 검증 Python 도구 설정`의 시드 기록은 `outputs/resource-ui-seed.json`에 있다. 파일 본문 초안과 테스트 워크플로 편집은 서버 저장하지 않았다. 기존 사용자 5173 탭·DB·워크플로·자료를 편집하지 않았다.
