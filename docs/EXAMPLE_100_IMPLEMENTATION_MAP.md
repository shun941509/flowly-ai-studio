완료 상태는 로컬 실행 계약의 구현 범위입니다. 실모델 정답률이나 회사 시스템 연결 성공을 뜻하지 않습니다. 명시된 수용조건과 실패·대기 시나리오는 실제 내보낸 두 실행기로 별도 검증합니다.
