# 디자인·운영용 내보내기 통합 작업 · 2026-10-26

현재 작업의 계약과 검증 기록이다. 이전 통합 보고의 통과 수치를 이번 검증으로 합산하지 않는다. 기존 미커밋 파일·D1·워크플로·자료를 보존한다.

## 공통 계약과 책임

- 통합: `studio-theme.css`의 공통 색상·간격·입력 규칙, CSS import 순서, 빌드·브라우저 확인·최종 기록.
- 편집기: `studio.tsx`, `canvas.tsx`, `workbench.tsx`, `editor-layout.css`. 기존 그래프/JSON/입출력/권한 계약을 유지하며 외곽 패널만 교체한다.
- 페이지: `workflow-sharing.tsx`, `workflow-guide.tsx`, `example-catalog.tsx`, `example-customizer.tsx`, `studio-pages.css`, 테스트 로그인 HTML/스타일. `WorkflowList.actions`로 제목과 작업 버튼을 함께 배치한다.
- 내보내기: `export.tsx`, `export-prompt.tsx`, `export-ui.css`, 패키지 생성·로컬 운영 환경·관련 테스트. 테스트 대역은 저장소에서만 제공한다.

새 스키마·DB 이관·캔버스 라이브러리 교체·외부 모델 연결을 추가하지 않는다. 공통 토큰은 흰색 surface, indigo primary, slate 본문/보조 설명과 구분되는 성공·주의·오류 색상이며 기존 로고를 유지한다. 준비된 Tailwind 컴포넌트를 무작정 초기화하지 않고 기존 CSS와 설치된 resizable primitive를 재사용한다.

## 운영용 내보내기 경계

웹의 네 가지 내보내기(Node.js/Python/AI 지시 복사/Agent 다운로드)는 유지한다. 기존 대화상자에는 개발/운영 토글이 없으며 실제 개발 환경 선택은 내려받는 로컬 프로필에 존재했다. 새 프로젝트는 운영 환경으로 제공하고 기존 프로필의 실행 기록은 보존한다. 실제 키·테스트 대역·개발 서버를 패키지에 넣지 않는다. `.env.example`, 파일 일치 검사, 사용자 실행 검증, 로컬 운영 화면, 로그·승인·재개·복구는 운영 기능으로 유지한다. 운영용 패키지 제공은 실제 서비스 연동·배포 검증 완료를 의미하지 않는다.

### 운영용 패키지

- 내보내기 대화상자와 ZIP에는 원래 개발 서버·HMR·test fixture가 없었다. 실제 제거 대상은 로컬 화면의 개발 프로필 기본값과 개발/운영 선택이었다.
- 새 기본 프로필은 `production`, 설정 파일은 프로젝트 루트의 `.env`다. 신규 `production=false` 프로필 등록을 거절하고 모든 프로필에 운영 확인을 요구한다.
- 이전 프로필의 이름·환경 경로·실행 기록은 보존한다. 구형 개발 플래그만으로 대기열을 잘못 거절하던 비교를 수정했으며 실제 환경 파일 변경 검사는 유지한다.
- `START_HERE.md`, `AI_START.md`, `AI_PROMPT.md`, `AGENTS.md`, Agent 패키지의 `Agent.md`·진입점·manifest, 선택 Skill/자료/MCP 정의, 원본 `workflow.json`, 설계 설명, 두 언어 실행기, `.env.example`, `flowly_local.py`, `flowly_ops.py`, `OPERATIONS.md`, 파일 일치 검사와 왕복 수정 안내를 유지한다.
- 실제 키·토큰·`.env`·저장소 테스트 대역은 넣지 않는다. 설정 누락 시 `unconfigured`와 다음 설정 항목을 안내하며 가짜 응답으로 전환하지 않는다.
- 웹의 로컬 TEST 로그인과 개발 저장소의 테스트는 검증을 위한 기능으로 유지한다. 사용자에게 내려주는 운영용 프로젝트와 구분한다.

### 브라우저 확인

- 1280×720, 1440×900, 1920×1080에서 편집기와 설정창을 확인했다. 1280 화면의 설정 본문은 높이 212px 안에서 2,776px 내용을 스크롤하며 마지막 항목에 도달했다. 변경 전에는 본문 높이 자체가 2,640px로 늘어났다.
- 800×720에서는 세로 패널을 확인했다. 보강 후 캔버스 290px·설정 220px·설정 본문 116px로 표시되며 페이지 세로 스크롤을 사용한다. 가로 넘침은 없다.
- 경계 드래그와 방향키 조절 후 시점 유지, 휠 확대(26%→63%), 영역 선택 5개, 전체 선택·방향키 이동·실행 취소, 연결 추가(5→6)와 취소(6→5), 이동 도구를 확인했다. 작은 배율의 연결점은 키보드 Enter로도 연결했다.
- 실제 조회자 계정에서 palette 없이 두 패널을 확인했고 저장·설정 입력은 비활성, 가이드·다운로드는 접근 가능했다. Agent 없는 합성 흐름을 실제 화면에서 ZIP으로 다운로드했다.
- 가이드 Escape 닫기와 호출 버튼으로 포커스 복귀, 선택 블록·배율 보존을 확인했다. 중첩 편집의 미적용 4개 노드 초안을 보관→재열기→복구했고 상위 3개 노드는 적용 전까지 바뀌지 않았다. 메인·중첩 패널 DOM ID 중복이 없다.
- 새 로그인·예제·가이드·공유 목록·내보내기 화면을 확인했다. 콘솔 오류는 관찰되지 않았다.

전후 캡처와 화면별 상세 확인: [화면 비교 기록](qa/DESIGN_PRODUCTION_UI.md).

### 사용자 설정과 남은 확인

1. ZIP을 새 폴더에 풀고 `START_HERE.md`를 읽는다. 로컬 운영 화면은 Python 3.11 이상, Node 프로젝트 실행에는 Node.js 22.13 이상도 필요하다.
2. `python flowly_local.py`로 로컬 화면을 열고 필요한 연결만 설정한다. 모델은 `OPENAI_API_KEY`·`FLOWLY_MODEL`, MCP 주소·토큰은 해당 ZIP의 `.env.example`과 안내에 적힌 환경 변수로 등록한다. 웹 Flowly에 키를 입력하지 않는다.
3. 운영 환경 사용을 허용하고 설정 확인 후 새 실행을 시작한다. 실제 외부 연결 점검은 사용자가 별도로 선택하는 기능이다.

실제 모델 답변 품질, 사내 MCP·운영 SSO·배포 연결은 미검증이다. 최신 패키지로 대표 6개를 다시 검증했으며 **나머지 221개는 이번 패키지 기준으로 재검증하지 않았다**. 예제 배지 역시 새 증거가 있는 경우에만 실행 검증을 표시한다.

브라우저 Ctrl+확대는 현재 in-app 자동화에서 확대율이 바뀌지 않아 실제 브라우저 125%/150% 확대 검증으로 계산하지 않았다. 좁은 CSS viewport 검증과 구분한다. 프롬프트 생성·복사 완료 UI·복사 함수 테스트는 통과했으나 자동화 도구의 가상 클립보드와 페이지 클립보드가 달라 외부 앱에 붙여넣는 왕복 검증은 완료하지 못했다. 실제 Cowork·Codex 작업 실행도 이번 검증 대상이 아니다.
